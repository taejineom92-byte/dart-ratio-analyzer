# DART 재무비율 분석기

DART 공시 데이터로 기업의 재무비율을 계산하고, 여러 회사를 비교하는 도구입니다.

## 준비
pip install requests pandas

## 사용법
python dart_ratios.py --sample                 # API 키 없이 연습
python dart_ratios.py 005930 --csv samsung.csv  # 실제 데이터 (DART_API_KEY 필요)
python compare.py                               # CSV 여러 개의 부채비율 비교

## 직접 개선한 부분
AI로 기본 코드를 만든 뒤, 신용분석 관점에서 문제를 찾아 고쳤습니다.

- **자본잠식 처리**: 자본이 음수면 부채비율·ROE가 마이너스로 나와 오히려
  양호해 보이는 착시가 생깁니다. 이 경우 N/A로 표시하고 경고를 띄웁니다.
- **재무상태표 검증**: 자산 = 부채 + 자본이 맞지 않으면 계정 추출 오류로
  보고 경고합니다.
- **여러 회사 비교** (compare.py): CSV를 합쳐 부채비율 순으로 정렬합니다.

## 실행 예시
| 회사 | 부채비율 |
